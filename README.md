# ACT Lutas Caieiras — esboço de site

Proposta visual de site para a **ACT Academia de Lutas**, no centro de Caieiras – SP.
É uma versão de apresentação para o cliente, não o site oficial.

- Modalidades: Muay Thai, Boxe, Jiu-Jitsu, Jiu-Jitsu Kids, Funcional + TRX
- Horários: grade de exemplo, a confirmar com a academia
- Botão do WhatsApp: ilustrativo

Página única (`index.html`), sem build. Para ver localmente, abra o arquivo no navegador.
